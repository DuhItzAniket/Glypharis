- GDC-scan is one document and numbers only: no text, word, confusion, category or example table is built for it. FUNSD and IIIT5K: character and class tables and counts only.
- OmniDocBench's reference unit is a layout block: it gets the reading-order rows only (no page budget, unmatched lines, cropping error or detection rows).

- GDC: a quoted line carries its document key, source URL and licence (arXiv CC BY 4.0, whose abstract page names title and authors; US federal and Gutenberg works public domain); lines of the CC BY-SA 3.0 textbooks (hefferon_linalg, mit_mcs) are listed by id and numbers only.
- Examples: type k (counted from 1) is drawn with `default_rng([20261115, k])`, the error and correct crops with seed 20261115.
- GDC is 106 pages from 21 documents; the document-cluster intervals with 18 to 21 clusters cover less than nominal. The blur attribute is measured on 64-px crops, so it mixes source resolution with optical blur. GlyphSynth and GLYPH-C are synthetic or derived from validation. H4 is read post hoc.
