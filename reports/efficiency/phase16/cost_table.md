# GW-EFF-007: what v1 costs on this laptop

HierText validation, 10 warm-up and 100 timed items, one process per run; CPU runs at 10 threads unless stated (torch intra and inter 10, each ONNX Runtime session intra-op 10, sequential). Means carry a descriptive 95% bootstrap interval over the timed items; p95 is a point value. A line is read with `TextRecognizer.read`, as the pipeline reads it (sorted by width, split at its line and column caps, at least 64 padding columns). VRAM: torch's `max_memory_allocated`, then nvidia-smi's memory at the end for this process (n/a where the Windows driver does not report it) and for the whole GPU (the display and other programs included).
